## Prévisualiser

Ouvre `CV_Mahery_FR.html` dans Chrome ou Edge (double-clic).

## Exporter en PDF

1. Ouvre le fichier HTML dans **Chrome** ou **Edge**
2. `Ctrl + P` → **Enregistrer au format PDF**
3. Paramètres recommandés :
   - Format : **A4**
   - Marges : **Par défaut** (ou Aucune si le rendu est correct)
   - **Graphiques d'arrière-plan** : activé
   - Échelle : **100 %**

## ATS — bonnes pratiques respectées

- Structure sémantique (`header`, `section`, `article`, `h1`–`h2`)
- Pas d'images pour le texte
- Sections nommées clairement (Profil, Compétences, Expérience, Formation, Projets)
- Mots-clés techniques listés en texte brut
- Police système lisible (Calibri / Arial)
- Liens en texte clair (email, LinkedIn, GitHub)
